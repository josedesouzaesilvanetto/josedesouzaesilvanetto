## 🧑🏽‍💻 Sobre Mim

Sou **José Neto**, profissional de tecnologia, dados e engenharia analítica com atuação focada em **Ciência de Dados, Arquitetura de Business Intelligence, Engenharia de Dados e Automação Inteligente com IA**.

Desenvolvo soluções corporativas de ponta a ponta: desde a extração, reconciliação e modelagem em bancos de dados relacionais e Data Warehouses até a entrega de painéis executivos auditáveis, APIs de alta disponibilidade, automações de processos críticos e agentes autônomos orientados a dados.
